1. 캐릭터 시트

캐릭터를 설명하면 후보 4장을 만듭니다. 마음에 드는 1장을 고르면 이후 모든 단계의 기준이 됩니다.

API 4회

2. 눈·입 위치

파란 박스는 눈, 주황 박스는 입입니다. 박스를 끌어서 옮기고, 오른쪽 아래 모서리를 끌어서 크기를 바꾸세요. 눈썹은 빼고 상하좌우에 조금 여유를 두면 됩니다.

3. 일관성 테스트

기준 시트를 참고해 장면·각도가 다른 컷을 만듭니다. 기준과 같은 사람으로 보이는 컷을 눌러서 체크하세요. 80% 이상이면 합격입니다.

API 20회

4. 표정 5종

기준 시트에서 표정만 바꾼 베이스를 만듭니다. 숫자는 얼굴 밖(머리·옷·배경)이 얼마나 바뀌었는지입니다. 낮을수록 좋고, 25를 넘으면 구도가 틀어진 것입니다.

API 4회 (기본 표정은 시트 그대로)
10 이하 양호10~25 주의25 초과 구도 틀어짐

5. 눈·입 파츠

표정마다 눈 감음, 입 조금, 입 크게를 만들고 박스 부분만 잘라 붙입니다. AI가 그림을 밀거나 색을 바꾼 경우 자동으로 맞춘 뒤 이음매(붙인 자리가 티 나는 정도)를 잽니다.

6. 미리보기·결과

만든 파츠로 눈 깜빡임과 말하기를 바로 재생합니다. 오른쪽은 0단계 합격 기준입니다.
