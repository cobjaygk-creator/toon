# 썰툰 제작기

대본을 넣으면 장면별 캐릭터를 만들고, 입과 눈만 움직여 썰툰 영상을 만드는 도구입니다.
현재 진행 상황
- **0단계 기술검증**: 검증 도구 완성. 실제 Gemini 테스트는 결제 설정 후 진행 예정
- **1단계 최소 파이프라인**: 제작기(`web/sseoltoon-maker.html`) 완성. 대본 → 컷 편집 → Gemini 음성 → 입·눈 움직임·효과음·배경음악 → MP4 저장, 작업 저장/불러오기
- Gemini 무료 등급: 음성은 모델당 하루 10회, 이미지는 사용 불가 (실사용은 결제 필요)

## 구성

| 폴더 | 내용 | 실행 방법 |
| --- | --- | --- |
| `web/sseoltoon-maker.html` | **썰툰 제작기**: 대본 → 컷 → 음성 → 입·눈 움직임 → WebM 영상 | 크롬·엣지로 열기. 설치 없음 |
| `web/sseoltoon-checker.html` | 캐릭터 검증기: 캐릭터 시트·표정·눈입 파츠 생성 후 .zip 저장 | 크롬·엣지로 열기. 설치 없음 |
| `poc/` | PC용 검증 스크립트 (Node.js + TypeScript) | `poc/README.md` 참고 (Windows는 `setup.bat` → `run.bat`) |

두 버전은 같은 일을 합니다. 웹 검증기가 더 쓰기 쉽고, PC 버전은 결과 파일을 폴더 단위로 남기고 싶을 때 씁니다.

## 제작기 사용 순서

1. 대본: `이름: 대사`, `(나레이션)`, `[장면: 장소]` 형식으로 입력 → 컷 나누기
2. 캐릭터·목소리: 등장인물마다 목소리 선택. 검증기에서 저장한 캐릭터 .zip을 넣으면 그 캐릭터로 교체
3. 컷 확인: 표정·구도(원샷/2인 대화/클로즈업) 자동 지정, 직접 수정 가능
4. 음성 만들기: Gemini TTS (데모 모드는 웅얼거리는 소리)
5. 미리보기·저장: 입 모양은 음성 크기에 맞춰, 눈은 3초 간격으로 깜빡임. 자막·장소 캡션·천천히 줌인·충격 컷 집중선과 흔들림 포함. MP4로 저장(지원 안 되는 브라우저는 WebM)

그 밖에: 장소별 배경 그림 넣기, 효과음(장면 전환·충격)과 배경음악(잔잔/긴장), 대사 수정·순서 변경·삭제, 컷 하나만 음성 다시 만들기, 작업 파일(.json) 저장·불러오기

## 0단계 검증 순서

1. 캐릭터 시트 후보 4장 생성 → 하나 고르기
2. 눈·입 위치(박스) 지정
3. 일관성 테스트: 같은 캐릭터로 장면이 다른 컷 생성, 같은 사람으로 보이는 비율 80% 이상이면 합격
4. 표정 5종 (기본·웃음·화남·슬픔·놀람)
5. 표정별 눈 감음·입 2단계 파츠 생성 → 위치·색 자동 보정 → 이음매 점수 5 이하면 합격
6. 깜빡임·말하기 미리보기와 합격 판정

## 사용 기술

- 이미지: Google Gemini 이미지 모델 (기본 `gemini-nano-banana-2.1`). **무료 등급에서는 이미지 생성이 막혀 있어 결제 설정이 필요합니다.**
- 음성: Gemini TTS (1단계부터 사용 예정)
- 영상: 브라우저 캔버스 합성 → WebM 출력 (1단계부터)

## 다음 단계

0단계 4가지 기준을 통과하면 1단계로 넘어갑니다. 1단계는 대본 → 장면 분할 → 음성 → 입·눈 움직임 → 1분 샘플 영상입니다.
