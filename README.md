# 썰툰 제작기

대본을 넣으면 장면별 캐릭터를 만들고, 입과 눈만 움직여 썰툰 영상을 만드는 도구입니다.
지금은 **0단계 기술검증** 단계입니다. AI로 만든 캐릭터를 베이스·눈·입 레이어로 나눠 합성했을 때 티가 나지 않는지 확인합니다.

## 구성

| 폴더 | 내용 | 실행 방법 |
| --- | --- | --- |
| `web/` | 웹 검증기 (HTML 파일 하나) | `sseoltoon-checker.html`을 크롬·엣지로 열기. 설치 없음 |
| `poc/` | PC용 검증 스크립트 (Node.js + TypeScript) | `poc/README.md` 참고 (Windows는 `setup.bat` → `run.bat`) |

두 버전은 같은 일을 합니다. 웹 검증기가 더 쓰기 쉽고, PC 버전은 결과 파일을 폴더 단위로 남기고 싶을 때 씁니다.

## 0단계 검증 순서

1. 캐릭터 시트 후보 4장 생성 → 하나 고르기
2. 눈·입 위치(박스) 지정
3. 일관성 테스트: 같은 캐릭터로 장면이 다른 컷 생성, 같은 사람으로 보이는 비율 80% 이상이면 합격
4. 표정 5종 (기본·웃음·화남·슬픔·놀람)
5. 표정별 눈 감음·입 2단계 파츠 생성 → 위치·색 자동 보정 → 이음매 점수 5 이하면 합격
6. 깜빡임·말하기 미리보기와 합격 판정

## 사용 기술

- 이미지: Google Gemini 이미지 모델 (기본 `gemini-nano-banana-2.1`). **무료 등급에서는 이미지 생성이 막혀 있어 결제 설정이 필요합니다.**
- 음성: Gemini TTS (1단계부터 사용 예정)
- 영상: 브라우저 캔버스 합성 → WebM 출력 (1단계부터)

## 다음 단계

0단계 4가지 기준을 통과하면 1단계로 넘어갑니다. 1단계는 대본 → 장면 분할 → 음성 → 입·눈 움직임 → 1분 샘플 영상입니다.
